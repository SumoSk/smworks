# SM Works

เว็บไซต์ขายบริการสร้างเว็บไซต์ธุรกิจและคลินิก พร้อมระบบหลังบ้านเป็นตัวเลือก แทนเกม Traffic Fixer Thailand ตามคำสั่งเจ้าของโปรเจกต์

Static HTML/CSS/JavaScript ไม่มี build step ใช้ GitHub Pages จาก main / root และเชื่อม API เดิมสำหรับรับคำขอประเมินงานและระบบผู้ดูแล

- `index.html`: หน้าขายบริการภาษาไทย
- `styles.css`, `app.js`: responsive design, interactive demos, project brief
- `examples/`: ตัวอย่างเว็บไซต์ 4 ธุรกิจ ข้อมูลสมมติ มี noindex
- `play-ipad.html`, `play-v2.html`: ส่งลิงก์เกมเดิมไปยังหน้าขายบริการ

SM Works แสดงช่องทางติดต่อธุรกิจที่เจ้าของแจ้ง: LINE ID `sumoskb` (ลิงก์บัญชีส่วนตัวแบบ `line.me/ti/p/~sumoskb`), อีเมล `sumoskb@hotmail.com` และโทร `096-859-5151` แบบฟอร์มส่งคำขอผ่าน API เดิมและแจ้งผลตามการตอบกลับของระบบ พร้อมช่องทางอีเมลและ LINE เป็นทางเลือก

ผล Google/AI ไม่รับประกัน ไม่ใส่ราคาหรือคำรับรองที่ไม่มีหลักฐาน ระบบหลังบ้านในหน้าขายเป็น demo ภาพรวม ไม่ใช่ระบบลูกค้าจริง

ก่อนเปิดบริการเต็มรูปแบบ ควรทดสอบว่า LINE ID ที่ระบุเปิดบัญชีได้จากเครื่องลูกค้าและตั้งค่าให้ค้นหาจาก ID ได้ และยืนยันว่าต้องการใช้บัญชีส่วนตัวหรือ LINE Official Account รวมถึงกำหนดแพ็กเกจ ราคาเริ่มต้น (ถ้ามี) จำนวนรอบแก้ไข และระยะเวลาดำเนินการจากข้อมูลจริง สำหรับการติดตาม conversion/search ให้เชื่อมบริการ Analytics และ Search Console ภายหลังด้วยบัญชีเจ้าของ พร้อมแจ้งนโยบายความเป็นส่วนตัวให้ตรงกับการใช้งานจริง
