# SUMO WEB

เว็บไซต์ขายบริการสร้างเว็บไซต์ธุรกิจและคลินิก พร้อมระบบหลังบ้านเป็นตัวเลือก แทนเกม Traffic Fixer Thailand ตามคำสั่งเจ้าของโปรเจกต์

Static HTML/CSS/JavaScript ไม่มี build step และไม่มีฐานข้อมูล ใช้ GitHub Pages จาก main / root

- `index.html`: หน้าขายบริการภาษาไทย
- `styles.css`, `app.js`: responsive design, interactive demos, project brief
- `examples/`: ตัวอย่างเว็บไซต์ 3 ธุรกิจ ข้อมูลสมมติ มี noindex
- `play-ipad.html`, `play-v2.html`: ส่งลิงก์เกมเดิมไปยังหน้าขายบริการ

ชื่อแบรนด์ SUMO WEB เป็นชื่อชั่วคราว ยังไม่มีช่องทางรับลูกค้าเฉพาะที่เจ้าของยืนยัน แบบฟอร์มสร้างรายละเอียดให้คัดลอกหรือดาวน์โหลดเท่านั้น ไม่ส่งและไม่บันทึกข้อมูล ไม่ใส่ข้อมูลส่วนตัวหรือช่องทางคลินิกเป็นช่องทางธุรกิจโดยอัตโนมัติ

ผล Google/AI ไม่รับประกัน ไม่ใส่ราคาหรือคำรับรองที่ไม่มีหลักฐาน ระบบหลังบ้านในหน้าขายเป็น demo ภาพรวม ไม่ใช่ระบบลูกค้าจริง

เมื่อมีช่องทางติดต่อจริง ให้เพิ่มลิงก์ LINE/โทร/อีเมลในหน้า contact และแก้ข้อความแบบฟอร์มให้ตรงกับวิธีรับข้อมูล โดยไม่อ้างว่าข้อมูลส่งแล้วถ้ายังไม่มีระบบรับข้อมูล

ประวัติเกมเดิมคงอยู่ใน Git commit ก่อนการเปลี่ยนหน้า สามารถย้อนคืนได้โดยไม่ลบประวัติ
